# ICDFA Practical Laboratory 1
## Network Commissioning and Connectivity Verification

### Overview

This laboratory focuses on the commissioning and verification of a controlled virtual network environment using VMware Workstation, Ubuntu and OPNsense.

### Objectives

- Verify IPv4 network configuration
- Verify default gateway and routing
- Test local network connectivity
- Test Internet connectivity
- Verify DNS resolution
- Capture and analyse network traffic using Wireshark

### Environment

- **Virtualisation Platform:** VMware Workstation
- **Client Operating System:** Ubuntu
- **Firewall:** OPNsense
- **Network:** ICDFA-LAN
- **LAN Addressing:** 10.10.10.0/24
